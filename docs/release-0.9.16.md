# NodeTaxi 0.9.16

Curved route line.

- Catmull-Rom smoothing is applied to the world-map and minimap route polyline.
- Corridor right angles and branch joins now render as curves.
- Rendering-only change; node selection and detour limits are unchanged.
- The line still passes through the selected route points.

Requires TomTom. Install into `_forever_/Interface/AddOns/NodeTaxi`.
Source: https://github.com/rmburgess-dev/NodeTaxi
