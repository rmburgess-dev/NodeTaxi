# NodeTaxi 0.9.5

Show the whole node field.

- Draw every known node in each route zone as a small, faint resource icon.
- Selected route nodes remain bright and connected by the dashed node-to-node
  journey line.
- `/nt allnodes on|off` toggles the full field; default is on.
- Tracking filter still applies, so miners see ore and herbalists see herbs.
- Corridor remains hidden.

Requires TomTom. Install into `_forever_/Interface/AddOns/NodeTaxi`.
Source: https://github.com/rmburgess-dev/NodeTaxi
