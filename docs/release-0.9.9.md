# NodeTaxi 0.9.9

Smooth node sweeps.

- Leave the corridor at a node cluster's projection.
- Curve through the selected node(s) using Catmull-Rom smoothing.
- Rejoin the corridor at the next point ahead; no straight return spur.
- Keep the 75-yard maximum deviation (`/nt spur`).
- Keep the whole-map all-node field and corridor reference.

Requires TomTom. Install into `_forever_/Interface/AddOns/NodeTaxi`.
Source: https://github.com/rmburgess-dev/NodeTaxi
